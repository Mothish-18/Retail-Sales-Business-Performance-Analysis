# Project Methodology

## Retail Sales & Business Performance Analysis

### 1. Project Workflow

The project was completed using three main stages: Excel data preparation, SQL analysis and Power BI dashboard development.

### 2. Stage 1 – Excel Data Preparation

**Tool:** Microsoft Excel

Activities performed:

- Imported the raw retail sales dataset.
- Identified and removed duplicate records.
- Cleaned inconsistent text values.
- Handled missing customer names.
- Corrected column formats.
- Created calculated columns.
- Used Excel formulas and PivotTables for initial analysis.

**Output:** Cleaned retail sales dataset containing 10,000 records.

### 3. Stage 2 – SQL Data Analysis

**Tool:** MySQL

Activities performed:

- Created the retail sales database and table.
- Imported the cleaned dataset.
- Checked total records and duplicate records.
- Validated missing and incorrect values.
- Analyzed total revenue and profit.
- Compared category and regional performance.
- Identified top-performing products and customers.
- Analyzed monthly revenue trends.

**Output:** SQL queries and business analysis results.

### 4. Stage 3 – Power BI Dashboard Development

**Tool:** Microsoft Power BI

Activities performed:

- Connected Power BI to the MySQL database.
- Created six DAX measures.
- Designed KPI cards.
- Created revenue and profit charts.
- Analyzed product and category performance.
- Analyzed customer and regional performance.
- Added interactive Year, Region and Category slicers.

**Output:** Three-page interactive Power BI dashboard.

### 5. Dashboard Pages

| Page | Dashboard Name | Main Analysis |
|---|---|---|
| 1 | Executive Overview | Revenue, profit, orders and sales trends |
| 2 | Product & Category | Product profitability and category performance |
| 3 | Customer & Regional | Customer contribution and regional performance |

### 6. Final Project Deliverables

- Raw retail sales dataset.
- Cleaned retail sales dataset.
- Excel analysis workbook.
- MySQL database and SQL scripts.
- Six DAX measures.
- Three-page Power BI dashboard.
- Project documentation.

### 7. Conclusion

This project demonstrates an end-to-end retail sales analysis workflow using Excel, MySQL and Power BI. It converts raw sales data into structured information and interactive visual reports to support business performance analysis.

**Dataset Note:** The project uses synthetic data created for portfolio and learning purposes.
